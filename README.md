# Instagram Clone Web Application 📸 ✨

مشروع متكامل ومطور يحاكي منصة إنستغرام (Instagram) بأحدث معايير الويب والتصميم التفاعلي لعام 2026.

---

## 🚀 كيفية تشغيل المشروع (How to Run)

لتشغيل السيرفر المحلي:

```bash
# باستخدام npm:
npm start

# أو مباشرة عبر Node.js:
node server.js
```

افتح المتصفح على:
👉 **[http://localhost:3000](http://localhost:3000)**

---

## 🌟 أبرز مميزات التحديث الشامل (Major Features & Upgrades)

### 🌓 1. الوضع الليلي والنهاري (Dark & Light Mode)
- دعم كامل للوضع الليلي الحقيقي (True Dark Theme) والنهاري بضغطة زر.
- حفظ اختيار الثيم تلقائياً في `localStorage`.
- تكيف الألوان والأيقونات والخلفيات والشعارات بانسيابية فائقة.

### ➕ 2. نافذة إنشاء منشور جديد حقيقي (Create Post Modal)
- إمكانية رفع صورة من جهازك أو اختيار صورة جاهزة من العينات.
- **فلاتر إنستغرام الحية:** تطبيق فلاتر فورية على الصورة (Clarendon, Gingham, Moon B&W, Lark, Reyes).
- كتابة كابشن وإضافة المنشور فورياً ليظهر في أعلى الـ Feed مع أنيميشن سلس ويُحفظ في المتصفح.

### ❤️ 3. تفاعل المنشورات المتقدم (Interactive Feed)
- **Double Tap to Like:** النقر المزدوج على أي صورة يُطلق قلب إنستغرام الأبيض الكبير النابض في المنتصف!
- **عداد الإعجابات التفاعلي:** زيادة ونقصان الإعجابات وتغيير لون القلب للأحمر الفاقع.
- **حفظ المنشورات (Bookmark):** حفظ أي منشور وإضافته مباشرة إلى تبويب المحفوظات (Saved).
- **التعليقات الحية:** إمكانية إضافة تعليق وحذفه فوراً.
- **مشاركة ونسخ الرابط:** نسخ رابط المنشور وعرض إشعار Toast طافي.

### ⏱️ 4. عارض القصص المتكامل (Instagram Stories Viewer)
- فتح القصص بملء الشاشة مع شريط تقدم زمني أوتوماتيكي مدته 5 ثوانٍ.
- أزرار التنقل بين القصص (السابق والتالي)، وإمكانية الرد على القصة أو إرسال تفاعل ❤️.

### 🔍 5. درج البحث السريع (Search Drawer)
- بحث فوري في القائمة الجانبية عن المستخدمين بالاسم أو المعرف (@handle).
- عرض نتائج البحث المباشرة مع الصور والتفاصيل.

### 🔔 6. درج الإشعارات (Notifications Drawer)
- عرض قائمة بالإشعارات والنشاطات الأخيرة (الإعجابات، المتابعات، الإشارات).

### 👤 7. صفحة ملف شخصي فائقة التنسيق (Modern Profile Page)
- شبكة منشورات حديثة بنظام 3 أعمدة (3-Column Grid) مع تأثير التمرير الفاخر (Hover Overlay) لعرض عدد اللايكات ❤️ والكومنتات 💬.
- **نافذة تعديل البروفايل (Edit Profile):** تعديل الاسم، المعرف، البايو (Bio)، ورابط الصورة فورياً.
- **تبويب المحفوظات (SAVED):** عرض المنشورات التي قمت بحفظها من الـ Feed.
- **قوائم المتابعين (Followers & Following):** فتح نوافذ منبثقة تفاعلية للمتابعين مع أزرار Follow / Unfollow.

### 🔐 8. صفحات التسجيل والدخول المطورة (Login & Signup)
- زر إظهار/إخفاء كلمة المرور (Show/Hide Password 👁️).
- التحقق المباشر من صحة المدخلات.
- أزرار تفاعلية بألوان إنستغرام الرسمية وتأثيرات الضغط.
